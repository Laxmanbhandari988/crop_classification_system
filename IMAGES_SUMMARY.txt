╔══════════════════════════════════════════════════════════════╗
║              ADD CROP IMAGES - QUICK GUIDE                   ║
╚══════════════════════════════════════════════════════════════╝

PROBLEM:
  Your crops don't have images yet!
  The folder static/images/crops/ is empty.

SOLUTION:
  Add images using one of these methods:

══════════════════════════════════════════════════════════════

METHOD 1: AUTOMATIC (Recommended) 🚀

  Windows:
    Double-click: QUICK_ADD_IMAGES.bat
    Choose option 1

  Or manually:
    pip install Pillow requests
    python download_crop_images.py

  What it does:
    • Downloads real crop photos from Unsplash
    • Saves to static/images/crops/
    • Takes 5-10 minutes
    • Requires internet

══════════════════════════════════════════════════════════════

METHOD 2: PLACEHOLDERS (Fast) ⚡

  Windows:
    Double-click: QUICK_ADD_IMAGES.bat
    Choose option 2

  Or manually:
    pip install Pillow
    python create_placeholder_images.py

  What it does:
    • Creates colored placeholder images
    • Shows crop name on each
    • Takes 30 seconds
    • Works offline

══════════════════════════════════════════════════════════════

METHOD 3: MANUAL DOWNLOAD 📥

  1. Go to https://unsplash.com
  2. Search for crop names (rice, wheat, tomato, etc.)
  3. Download images
  4. Save as: static/images/crops/[cropname].jpg
     Example: static/images/crops/rice.jpg

══════════════════════════════════════════════════════════════

AFTER ADDING IMAGES:

  1. Restart Flask server
  2. Hard refresh browser (Ctrl+Shift+R)
  3. Visit "All Crops" page
  4. Get a recommendation

══════════════════════════════════════════════════════════════

WHAT YOU NEED IMAGES FOR:

  • 100+ crops in your database
  • Shows on recommendation result
  • Shows in crops browse page
  • Shows in crop detail page

══════════════════════════════════════════════════════════════

RECOMMENDATION:

  For quick testing:
    → Use METHOD 2 (placeholders)

  For production:
    → Use METHOD 1 (automatic download)

  For best quality:
    → Use METHOD 3 (manual download)
